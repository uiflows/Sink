# 运维操作手册

当前无已验收运行的 Sink Worker。以下为部署后的执行要求，不能理解为已完成。

每次更新先核实 mac02 账号、远端 commit、实例映射、迁移记录和备份。先测试，再发布；保留 Worker 版本标识。数据库结构变更必须单独评估兼容性，代码回滚不等于数据库恢复。

P0-B 上线验收应覆盖登录、创建、自定义短码、301/302、修改、删除、二维码、API、移动端、导入导出。只删除本轮有明确标记的测试链接。跨实例测试包含同短码不同目标、A 密钥访问 B 被拒绝、修改/删除 A 不影响 B。

P0-C 监测计划：每 10 分钟检查一次并加抖动，连续两次失败记为事件，状态恢复时再通知。检查 DNS、TLS、Worker、短链状态码、Location、循环、目标可访问性、备份新鲜度和用量。不得通过普通 HTTP 探测宣称知道第三方社交平台内部信誉。

邮件与 Webhook 渠道未配置，尚无真实告警送达测试。未配置渠道时须显示“未配置”，不能显示“已发送”。不创建 Codex 定时任务充当云端运行依赖。
