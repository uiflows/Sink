# 安全与权限

当前为部署准备阶段，安全验收未完成。禁止匿名创建短链，两个实例的登录和自动化凭据必须独立。所有修改、删除、批量操作需有可追溯审计；面向 Hub 的高风险调用必须保留人工批准。

已做：双实例部署命名校验、账号显式指定、资源归属检查、禁止误绑正式路由、默认关闭 Workers AI。配置、代码、日志和 Git 不保存生产 Secret。

待做：Sink 原版写入 Schema 仅做 URL 格式检查，不能据此认定已阻止私网和危险 URL。原版 public-url.ts 对抓取入口有基础拦截，但 DNS 重绑定、重定向后的私网目标、元数据抓取和创建入口仍需专门验证。未完成 P0-C 前不对外推广，也不宣称已具备完整 SSRF 防护。

Cloudflare API 的分析读取凭据遵循官方推荐的 Account Analytics Read，仅限目标账号；两份独立 Token 不构成数据集级 ACL。若需要账号级强隔离，必须另做账号方案，不能自动迁移现有业务。

只读枚举现有 Pages 时，接口包含已有明文管理变量。未将该值复制到项目、文档或 Git；建议所有者另行轮换，本轮不修改现有网站凭据。
